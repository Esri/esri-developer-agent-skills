# Security Policy

This repository packages technology-specific guidance and access to Esri documentation. This is done mostly with
markdown (.md) files and JSON configurations. While we do not expect code vulnerabilities, we also need to protect
against exposed secrets.

## Reporting a Vulnerability

To check the status of open security issues, go to [Security and quality](https://github.com/Esri/esri-agent-skills/security).

To report a security issue, use [Report a security concern](https://trust.arcgis.com/en/security-concern/).
